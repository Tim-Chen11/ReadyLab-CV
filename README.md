# ReadyLab-ML


The ReadyLab-ML/data/raw store the unprocess or file help for the data fetching
The ReadyLab-ML/data/metadata xlsx files are the files with structured fetched data, other file is generated by processed_metadata.py for future training

scripts:
    1. analyze_dataset, create_splits, feature_cluster for generate the json data for future trainning. e.g. processed_metadata.py in data folder
    2. setup_pipeline is the main logic that combines all the above for data clean and generation
    3. train.py is the main logic for starting the training process


transforms.py: Pure image preprocessing logic
url_dataset.py: Pure data loading logic
data_utils.py: Business logic that combines everything

 Training command example: python -m scripts.train --model_name resnet50 --use_cached --epochs 30 --batch_size 32 --num_workers 8 --learning_rate 0.001 --weight_decay 0.01 --loss label_smoothing --label_smoothing 0.2 --early_stopping 10 --use_amp --multi_task --decade_weight 1.0 --cluster_weight 1.0
